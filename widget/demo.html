This is a stand-in for a tenant's real website. The chat bubble in the bottom-right corner is the embedded support widget -- everything below this line is just placeholder content to show the widget floating over a normal page.

To try it against your own local backend, run the API (docker compose up --build from the repo root), create a tenant via /api/v1/auth/signup, upload a document, and update the data-tenant-slug below to match.
